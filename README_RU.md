# Secure Notes — сборка APK через GitHub Actions

Проект подготовлен для облачной сборки. **Android Studio и Android SDK на вашем компьютере не нужны.**

## Что умеет приложение

- Создание мастер-пароля и разблокировка по нему.
- Создание, редактирование и удаление заметок.
- Шифрование содержимого заметок AES-256-GCM.
- Вывод ключа из пароля через PBKDF2-HMAC-SHA256 (250 000 итераций).
- Автоматическая блокировка при уходе приложения в фон.
- Только локальное хранилище приложения; разрешение INTERNET не запрашивается.

## Внешний вид

Используется спокойная тёмная палитра: графитовый фон, тёмно-серые поверхности, светлый текст и нейтральные серые акценты. Ярко-синий акцент исходного варианта убран. Список заметок оформлен в виде неброских карточек.

## Как получить APK без Android Studio

1. Скачайте ZIP-архив проекта и распакуйте его на компьютере.
2. Откройте https://github.com и войдите в аккаунт (или зарегистрируйтесь).
3. Нажмите **New repository**. Назовите репозиторий `SecureNotes`. **Обязательно выберите Private (закрытый репозиторий)**: в проекте лежит персональный debug-ключ подписи, необходимый для установки будущих обновлений поверх текущей версии. Нажмите **Create repository**.
4. На странице нового репозитория выберите **Add file → Upload files**.
5. Перетащите в окно загрузки **все файлы и папки из распакованного SecureNotes**, включая скрытую папку `.github` и папку `signing`. В Linux в файловом менеджере нажмите `Ctrl+H`, чтобы показать скрытые файлы. Важно: загружайте содержимое папки, а не сам ZIP-файл.
6. Внизу страницы нажмите **Commit changes**. Ветка должна называться `main`.
7. Откройте вкладку **Actions**. Дождитесь завершения workflow **Build Secure Notes APK** со статусом зелёной галочки.
8. Откройте успешный запуск workflow. Внизу страницы в разделе **Artifacts** скачайте `secure-notes-debug-apk`.
9. Распакуйте скачанный архив — внутри будет `app-debug.apk`. Перенесите APK на Android-телефон и установите его. Android может попросить разрешить установку приложений из выбранного источника.

При каждом следующем push в ветку `main` APK будет собираться автоматически. Также сборку можно запустить вручную: **Actions → Build Secure Notes APK → Run workflow**.

## Технические параметры

- Package ID: `com.andrey.securenotes`
- `minSdk`: 26 (Android 8.0)
- `targetSdk` / `compileSdk`: 34
- JDK: 17
- Gradle: 8.2 (устанавливается на GitHub runner)
- Android Gradle Plugin: 8.2.0
- Kotlin: 1.9.22

Gradle Wrapper не включён: workflow устанавливает Gradle 8.2 непосредственно на облачном runner и вызывает `gradle assembleDebug`.

В проект включён отдельный **debug-ключ подписи** (`signing/secure-notes-debug.keystore`). Он нужен, чтобы APK, собранные в разные дни на разных GitHub runner, имели одну подпись и Android мог обновлять приложение поверх старой версии, сохраняя данные. Поэтому не удаляйте этот файл и держите репозиторий закрытым. Этот ключ предназначен только для личной debug-сборки — не используйте его для публикации в Google Play или для публичного распространения приложения.

## Важное предупреждение о пароле

Мастер-пароль не сохраняется. Если его забыть, восстановить зашифрованные заметки нельзя. Перед использованием храните пароль в надёжном менеджере паролей. Потеря/удаление данных приложения или сброс устройства также может привести к потере заметок: резервное копирование в этой версии не реализовано.

## Ограничения этой сборки

Это debug APK, подписанный тестовым debug-ключом GitHub runner. Для публикации в Google Play и безопасного обновления установленной версии потребуется отдельная release-сборка с постоянным ключом подписи. Не публикуйте пароль подписи или keystore в репозитории.
